# 🧠 Routine Optimizer

A smart productivity and habit-tracking application designed to help users organize daily schedules, manage tasks efficiently, and optimize routines through a clean and interactive interface.

---

## 🌐 Live Demo

🔗 https://routine-optimizer-1.onrender.com
---

## 🚀 Features

- 📅 Daily Routine Planning
- ✅ Task Management System
- 📊 Productivity Tracking
- 🔥 Habit Tracking
- 💾 CSV Data Storage
- 🎨 Clean and User-Friendly UI

---

## 🛠️ Tech Stack

- Python
- Tkinter / Streamlit
- Pandas
- CSV
